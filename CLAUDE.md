# Project rules

## Attribution policy (applies to all AI-assisted work)

NEVER include AI attribution or session links in any repository artifact.
This is a security requirement, not a style preference.

Banned everywhere (PR titles and descriptions, commit messages, issue and
review comments, code comments, docs):

- "Generated with Claude Code" footers or badges
- claude.ai / claude.ai/code session URLs
- Co-Authored-By or Claude-Session trailers referencing AI tooling
- Any equivalent from other AI tools
